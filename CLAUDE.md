# Hinweise für Claude

- Dieses Repo enthält die HTML-Lerneinheiten für Mathematik, gegliedert nach Jahrgangsstufe (`5/`, `6/`, …). Lernspiele, die selbst programmiert werden, kommen NICHT hierher, sondern in eigene Repos.
- Jede neue Einheit: Datei nach `<stufe>/<name>.html` (klein, Bindestriche, keine Umlaute), Eintrag im `units`-Array von `<stufe>/index.html` (Feld `thema` = Sequenz, z. B. "Brüche 1"). Neue Jahrgangsstufe zusätzlich in `index.html` im Array `stufen` eintragen.
- Öffentliche URL: `https://ldressel.github.io/Mathematik/<stufe>/<name>.html` (Groß-/Kleinschreibung beachten).
- Einheiten müssen eigenständig sein (eine Datei, offline lauffähig, iPad-tauglich, keine Speicherung von Schülerdaten).
- Im Unterrichtsmaterial (PDF) bekommt jede Aufgabe, die eine Einheit nutzt, einen QR-Code mit der öffentlichen URL.
