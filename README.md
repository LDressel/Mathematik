# Mathematik

Interaktive HTML-Lerneinheiten für den Mathematikunterricht an der Mittelschule Indersdorf, gehostet über GitHub Pages.

- Startseite: https://ldressel.github.io/Mathematik/
- Jahrgangsstufe 6: https://ldressel.github.io/Mathematik/6/

## Aufbau

```
index.html        Übersicht der Jahrgangsstufen
6/index.html      Übersicht Mathe 6 (Web-Clip für die Klasse)
6/<einheit>.html  einzelne Lerneinheiten
```

Neue Einheit: Datei in den Ordner der Jahrgangsstufe legen und in `<stufe>/index.html` im Array `units` eintragen. Dateinamen klein, mit Bindestrich, ohne Umlaute.

Die Seiten speichern keine Schülerdaten.
